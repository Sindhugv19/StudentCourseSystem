\# Student Course Management System



A menu-driven Student Course Management System developed in C.



\## Features



\- Student Registration

\- Add Courses

\- Drop Courses

\- Waitlist Management

\- Automatic Enrollment from Waitlist

\- Course Capacity Handling

\- Course Prerequisite Validation using Graph

\- Generate Student Transcript



\## Technologies Used



\- C Programming

\- Dev-C++

\- Graph Data Structure

\- Linked Lists

\- Queue



\## Project Structure



```

StudentCourseSystem/

│

├── main.c

├── student.c

├── student.h

├── course.c

├── course.h

├── graph.c

├── graph.h

├── fancy.h

├── StudentCourseSystem.dev

└── README.md

```



\## Compilation



Using GCC:



```bash

gcc main.c student.c course.c graph.c -o StudentCourseSystem

```



Run:



```bash

./StudentCourseSystem

```



(Windows)



```bash

StudentCourseSystem.exe

```



\## Menu



\- Register Student

\- Add Course
